I've built FinTrack, an offline personal finance manager for Windows 11, and prepared a portable preview.

Track LKR accounts, income, expenses and transfers, set monthly budgets, review spending reports, and export CSV or create local backups. The portable edition keeps its data beside the app.

Built with React, TypeScript, Tauri, Rust and SQLite.

Try the unsigned v0.9.1 prerelease: https://github.com/nilupul-madhusanka/fintrack-windows-11/releases/tag/v0.9.1

Requires Microsoft Edge WebView2 Runtime. Feedback is welcome while broader acceptance testing continues.
