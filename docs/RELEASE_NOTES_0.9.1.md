FinTrack now has a portable Windows 11 x64 edition: extract the ZIP and open FinTrack.exe. The database and WebView2 profile stay in a data folder beside the executable. No FinTrack installation is required.

Track LKR accounts, income, expenses, transfers and monthly budgets. Review spending reports, export filtered CSV, and create or restore verified local backups. Built with React, TypeScript, Tauri 2, Rust and SQLite.

Download the windows-x64-portable.zip asset and extract it to a writable folder. The matching .sha256 file verifies the ZIP. Microsoft Edge WebView2 Runtime must already be installed; it is not bundled in the portable ZIP.

This is an unsigned MVP prerelease. Clean-machine, disconnected-network and comprehensive native workflow acceptance remain pending. Data and backups are unencrypted. Close the app before moving its folder, keep a separate backup, and preserve the data folder when updating. See docs/PORTABLE.md for the complete guide.
